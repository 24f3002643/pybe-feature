# Project Context

This project builds a MERN learning module on recursion. Before doing
ANY work, read these files in full: docs/content-schema.md and
docs/project-build.md. They are the spec — follow them exactly, don't
improvise architecture or content.

Build in the milestone order defined in docs/project-build.md, Section 7
(M0 → M1 → M2 → M3 → M4). Do not skip ahead to M3 (backend) before M1/M2
(frontend, working end-to-end) are done and I've confirmed them.
